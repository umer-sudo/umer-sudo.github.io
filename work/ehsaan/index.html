Ehsaan

Pakistan had no
thrift marketplace.

A person-to-person marketplace app, brand system and launch campaign.

ClientSuleman Farooqui
DisciplineAI product · Brand · Launch
Timeline2026, in production
ScopeMarketplace app, identity, social, launch
The challenge

A category that
only existed in
Instagram DMs.

Second-hand clothing in Pakistan moved through comment sections, WhatsApp groups and DM negotiations. No listings, no search, no trust layer, nothing built for the people actually using it.

What we did

3 phases.

01

Twenty-three prompts to first build

React, Vite, TypeScript and Supabase through Lovable, then moved to Claude Code against a nineteen-section knowledge base so the product keeps its own rules as it grows.

02

A Gen-Z-native brand

Identity, type system and product design built for the audience that already trades this way — fast, visual, unembarrassed about second-hand.

03

The launch system

Social content, video and launch assets produced alongside the build, so the product and the campaign ship as one thing.

What we found

Trust is the product. Every design decision routed back to whether a stranger would send money for a stranger’s jacket.
